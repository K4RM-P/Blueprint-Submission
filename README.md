# GeekLoop

GeekLoop shows the value Free Geek Toronto creates to everyone involved: the businesses that donate laptops, the volunteers who refurbish them, and the people who buy them. Built for FUSE Blueprint 2026.

> Full judge-facing README is written in Stage 10.

```bash
pnpm install
cp .env.example .env.local   # fill in Supabase keys
pnpm dev                     # http://localhost:3000
```
